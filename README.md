# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/)'s HTML Foundations curriculum and **Practical Exercise 5: HTML Development**.

The website features a collection of recipes, recipe comparisons, a feedback form, and embedded cooking multimedia.

## Project Overview

Odin Recipes is a basic HTML website designed to demonstrate fundamental web development concepts while providing a simple way to explore different recipes.

## Features

- Homepage with recipe navigation
- Three recipe pages:
  - Lasagna
  - Chicken Adobo
  - Beef Steak
- Semantic HTML structure
- Recipe comparison table
- Feedback form with input fields, recipe selection, and rating
- Embedded YouTube cooking tutorial
- Accessibility practices, including descriptive image alternative text, form labels, semantic elements, and table headers

## Built With

- HTML5
- Git
- GitHub
- YouTube (embedded multimedia)

## Purpose

This project was created to apply the foundational HTML concepts learned through The Odin Project, including HTML elements, text, lists, links, images, boilerplate, and commit messages, while incorporating additional competencies required by the course.

These additional competencies include semantic HTML, tables, forms, multimedia, and accessibility practices.
