# Odin Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/), Foundations course.

## About

Odin Recipes is my first HTML project. It is a basic website containing a homepage that links to individual recipe pages.

## Recipes

- Lasagna
- Chicken Adobo
- Beef Steak

## Skills Practiced

- HTML boilerplate and document structure
- Headings and paragraphs
- Links and relative paths
- Images and alternative text (`alt`)
- Ordered and unordered lists
- HTML element nesting

## Built With

- HTML5
